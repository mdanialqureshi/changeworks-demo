# quillstack-billing documentation

- [Command line](cli.md): the `quill` commands and their options.
- [Tax regions](tax-regions.md): rates, currencies and rounding by
  region.
- [Rounding](rounding.md): how and where amounts are rounded.
- [Coupons and discounts](discounts.md): how coupons combine.
- [Dunning](dunning.md): the reminder schedule.
- [Export formats](export.md): CSV and JSON columns.

The library's modules live in `src/quillstack_billing/`; each module's
docstring is the reference for its rules, and these pages explain them
with examples. Every `>>>` example in these pages is run by the test
suite, so it is always current.
